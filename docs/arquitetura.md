# Geek de Boa Academy 2.0 — Projeto Integrado II

## Arquitetura
- Front-end: React, TypeScript e Vite
- Back-end: Node.js, Express e API REST
- Banco de dados: MySQL 8
- Administração do banco: MySQL Workbench
- IA: módulo experimental de geração assistida de questões

## Banco de dados
Schema: geekdeboa_academy

Entidades iniciais:
- usuarios
- cursos
- disciplinas
- assuntos
- questoes
- alternativas
- simulados
- tentativas
- respostas
- materiais

## Integração interdisciplinar
- POO: encapsulamento, classes de domínio, SOLID e Repository
- Engenharia de Software: requisitos, UML, backlog e arquitetura
- Qualidade de Software: testes, critérios de aceitação e integração contínua
- Governança em TI: indicadores, riscos, segurança e continuidade
- Direito e Legislação Empresarial: LGPD, direitos autorais e termos de uso
- Banco de Dados: modelo ER, normalização, SQL e integridade referencial

## Diretrizes
- Preservar as funcionalidades do PI I
- Adotar a identidade visual azul do Geek de Boa
- Implementar banco de questões, simulados e desempenho
- Integrar IA somente após estabilizar o fluxo principal
- Documentar decisões, testes e evidências para o relatório final
